# Yummy FOOD

موقع مطعم Yummy FOOD (ملف واحد: index.html).

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub بصفحة Public.
2. ارفع الملفين index.html و README.md إلى جذر المستودع (Add file ← Upload files).
3. من Settings ← Pages: في Source اختر Deploy from a branch، ثم الفرع main والمجلد / (root)، واضغط Save.
4. انتظر دقيقة أو دقيقتين، ثم افتح الرابط https://اسم-حسابك.github.io/اسم-المستودع/

## التعديل
افتح index.html وعدّل CONFIG (رقم واتساب، الهاتف، العنوان، ساعات العمل) وقوائم DISHES وOFFERS.
